About

Installation
Currently, Prayer Book with spoken prayers for Android is available as a side-load. I. e. It is not yet available on an app site. This is not a beta, but is a working release looking for users to test it and make suggestions or point out needed improvements to the spoken text portion of the app.

Sideloading an app on Android (installing an .apk or .apkmirror file from outside the official Google Play Store) is straightforward, but Google hides the setting by default to prevent accidental malware installations.

Because Android manages sideloading permissions on a per-app basis, you have to grant permission to the specific app (like Chrome or a file manager) that you are using to open the installer file.

In order to side-load the ap Prayer Book with spoken prayers:
  1. Download the APK file: Step 1: Use your Android browser (like Chrome) to download the .apk file from a trusted source (such as APKMirror or an official open-source repository). For the Prayer Book with spoken prayers, use this link: Prayer Book (spoken prayers, 11 MB)
  2. Open the file: Step 2: Once downloaded, tap the download completion notification, or open your device's Files app, go to the Downloads folder, and tap the APK file.
  3. Trigger the security prompt: Step 3: A system dialog will pop up saying, "For your security, your phone is not allowed to install unknown apps from this source." Tap Settings on that prompt.
  4. Toggle: Step 4: You will be taken directly to the settings page for the app you used to open the file (e.g., Chrome or Files). Flip the switch next to Allow from this source.
  5. Confirm the installation: Step 5: Tap the Back button to return to your file. A new prompt will ask if you want to install the application. Tap Install, then Done or Open once it finishes.
Notes:
  • If you are local (to me), I can install the app directly onto your phone using a USB cable.
  • If you are a developer, the Java code is available on GitHub at Prayer Book with Spoken Prayers.
  • If you ever want to revoke this permission later, or grant it ahead of time, you can find the master list in your settings:
    1. Open your device Settings.
    2. Go to Apps (or Apps & Notifications).
    3. Tap Special app access (usually found under an "Advanced" dropdown or by tapping the three dots in the top corner).
    4. Select Install unknown apps.
    5. Select the app you want to modify (e.g., your browser, F-Droid, or a file explorer) and toggle the permission on or off.
